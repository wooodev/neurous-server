# 🌟 neurous
## 📚 프로젝트 소개
> 글 읽기와 퀴즈, 데일리 미션, 보상을 통해 사용자의 문해력 성장을 목표로 하는 서비스

---
## ⚙️ 기술스택
- Java 21
- Springboot 3
- Mysql
- JPA
- Redis
- Docker
- GCP, Google gemini, Clova AI

## ⛏️ 주요 기능

- 컨텐츠 조회, 출석 체크
- 퀴즈 풀이 및 검증
- 퀴즈 난이도 체크 및 추천
- 미션 할당
- 경험치, 포인트 적용 및 사용
